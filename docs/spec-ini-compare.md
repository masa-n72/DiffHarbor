# DiffHarbor: INI ファイルの比較（M9）

## 目的
2 つの INI ファイルを、行の並びではなく [セクション] とキーで対応づけて比べる。並び順、空白、コメント、大文字小文字の違いは差異にしない。キーごとに値をコピーして保存できる。

## スコープ
- やる: キー単位の比較表示、行単位の比較との切り替え、キー / セクション / 全体のコピー、元に戻す、保存
- やる: 文字コード、改行コード、BOM は行単位の比較と同じく元のまま保存する
- やらない: 値の中の行内強調、キーの並べ替え、INI 以外の形式（JSON、YAML など）、行末コメント（`key=1 ; c`）の解釈

## インターフェース（diff-core `ini`）
```rust
pub enum IniStatus { Same, Changed, LeftOnly, RightOnly }
pub struct IniCell { pub line: Option<usize>, pub text: String } // 行番号と、表示する値（書かれたまま）
pub struct IniRow { pub section: String, pub key: Option<String>, pub left: Option<IniCell>,
    pub right: Option<IniCell>, pub status: IniStatus } // key が None ならセクションの行
pub struct IniDiff { pub rows: Vec<IniRow> }
pub fn is_ini_path(path: &Path) -> bool;
pub fn compare_ini(left: &[String], right: &[String]) -> IniDiff;
pub fn copy_edits(left: &[String], right: &[String], rows: &[usize], to: Side) -> Vec<LineEdit>; // to の側への編集
// merge.rs
pub struct LineEdit { pub start: usize, pub end: usize, pub new: Vec<String> }
impl History { pub fn apply_edits(&mut self, left, right, edits: Vec<LineEdit>, to: Side) -> bool; }
```

## 読み方
| 行（先頭の空白を除いて） | 扱い |
|---|---|
| 空 | 空行 |
| `;` または `#` で始まる | コメント。比較しない |
| `[` で始まり `]` を含む | セクション。名前は `[` と最初の `]` の間（前後の空白を除く） |
| `=` を含む | キー。最初の `=` の前がキー名、後が値 |
| それ以外 | 比較しない |

## 振る舞い
| 入力 / 状態 | 期待結果 |
|---|---|
| 左右どちらかの拡張子が `.ini`（大文字小文字を区別しない） | キー単位で開く |
| 「差分」→「行単位 / キー単位で比較」 | 表示を切り替える。編集の履歴と未保存の状態は共有する |
| セクション名、キー名 | 大文字小文字を区別しない。表示は左の綴り |
| 値 | 前後の空白を除き、両端が同じ引用符（`"` か `'`）なら外して比べる。大文字小文字は区別する |
| 最初のセクションより前のキー | 「（セクションなし）」として扱う |
| 同じセクションが 2 回出てくる | 1 つのセクションとしてまとめる |
| 同じセクションに同じキーが 2 つある | 出てきた順に 1 つ目同士、2 つ目同士を対応づける |
| 並び | 左の順。右だけにあるものは、右での直前の項目の後に入れる |
| セクションの状態 | 片側だけなら「左のみ」「右のみ」。両側にあり、キーがすべて同じなら「同一」、そうでなければ「変更」 |
| キーを右へコピー（両側にある） | 右の行の値の部分だけを左の値（書かれたまま）に置き換える。キー名の綴りと `=` の前後の空白は右のまま |
| 左のみのキーを右へコピー | 右のそのセクションの最後のキーの次の行に、左の行をそのまま入れる。キーがなければセクション見出しの次 |
| 右のみのキーを右へコピー | 右からその行を消す（左に合わせる） |
| 左のみのセクションを右へコピー | 右の末尾に、空行を 1 行あけて、左のセクション（見出しから次の見出しの前まで、末尾の空行を除く）を入れる |
| 右のみのセクションを右へコピー | 右からそのセクション（見出しから次の見出しの前まで）を消す |
| 両側にあるセクションを右へコピー | そのセクションの差異のあるキーをすべてコピーする |
| 片側だけのセクションの中のキーをコピー | セクションごとコピーする（消す） |
| すべて右へ | 差異のある項目をすべてコピーする。1 回の操作として元に戻せる |
| 左へのコピー | 左右を入れ替えて同じ |
| 次 / 前の差分 | 差異のある行（セクションの行を含む）へ移る |
| 「差異のみ」 | 同一のキーと、キーがすべて同一のセクションを隠す |
| コメント、空行 | 表示しない。コピーでは、消す範囲と入れる範囲（セクションごと）に含まれるものだけが動く |
